# 镜核 Electron MVP

## 首次安装

在 PowerShell 中执行：

```powershell
cd "D:\Working Projects\Screenshot tool\electron"
npm install
```

如果 Electron 运行时因网络原因未下载，可使用镜像重新执行安装脚本：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
node node_modules/electron/install.js
```

## 启动桌面应用

```powershell
cd "D:\Working Projects\Screenshot tool\electron"
npm run dev
```

应用会打开真正的 Windows 桌面窗口，不需要浏览器访问 `index.html`。

## 首个真实查询流程

1. 点击“新建核查任务”。
2. 输入一家企业名称，例如：`中招工业发展（北京）有限公司`。
3. 选择所需已适配站点。
4. 选择“可视化执行”，点击“开始执行”。
5. Electron 会打开所选网站，填写名称、识别图形验证码并提交查询。
6. 程序以系统 Edge/Chrome 的原生会话加载目标站，通过安全检查后再自动查询；页面结果准备完成后生成全页面截图。
7. 截图和 `任务汇总报告.xlsx` 会写入：

```text
文档\\镜核任务\\任务_时间戳\\企业名称\\信用中国_严重失信主体名单_时间戳.png
```

8. 任务完成后，在任务卡片点击“打开截图目录”。

## 验证码与反爬处理

- 任务使用独立的系统 Edge/Chrome 会话，先以原生方式加载页面并等待网站的 JS 安全检查完成，再连接 DevTools 协议执行查询和截图；浏览器窗口位于屏幕外，不抢占鼠标或键盘焦点。每次任务启动前和结束后都会回收该专用浏览器的整个进程树，避免占用后续任务的浏览器配置；用户自行打开的普通浏览器不受影响。
- 信用中国与中国执行信息公开网的图形验证码均由 `ddddocr` 在本机离线识别。图片会等待稳定加载后再送入 OCR；加载异常时优先使用页面自身的刷新控件恢复，仍失败才重新查询。每次异常会在任务目录的 `captcha-debug` 中保存诊断信息。
- 超过重试次数或安全检查无法通过时，该“企业 × 网站”条目会记录为“跳过”，备注失败原因，然后继续后续条目；任务不会等待人工处理。

## 当前 MVP 边界

- 当前真实适配站点为信用中国的“严重失信主体名单、重大税收违法失信主体名单”，中国执行信息公开网的“失信被执行人”，中国政府采购网的“政府采购严重违法失信行为记录名单”，军队采购网的“军队采购暂停名单、军队采购失信名单”，以及全国企业破产重整案件信息网的“企业破产重整案件信息”。均支持 PNG（完整 Windows 任务栏与系统时间）和网页 PDF（左上角生成时间、右下页码）留存。
- Excel 报告真实生成；Electron 模式支持读取 `.xlsx/.xls` 第一张表的第一列作为企业名单，手动输入和 CSV/TXT 也可用。
- 任务配置可选择留存方式：PNG 截图使用 Chromium DevTools Protocol 的 `Page.captureScreenshot` 一次性捕获页面内容（最大高度 20000 像素），并追加主显示器完整的 Windows 任务栏；网页 PDF 使用 Chromium 原生打印接口按 A4 横向分页保存结果页，每页左上角写入生成时的本机系统时间。
- 其他政府网站仍使用界面占位和站点清单，尚未接入执行适配器。
