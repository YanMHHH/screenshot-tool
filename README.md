## 🔧 核心改进总结

### ✅ 已完成的改进（2026-08-24）

#### 1. 降低被检测概率
- **浏览器指纹伪装**：移除 `navigator.webdriver`，添加反自动化参数
- **人类行为模拟**：随机点击位置、延迟、鼠标移动、页面滚动
- **反检测脚本注入**：伪装浏览器指纹和属性
- **替换所有点击操作**：W-001、W-002、W-004 的所有 `.click()` 替换为人类化操作

#### 2. 提高鲁棒性
- **智能等待机制**：等待元素可见、可交互、页面完全加载
- **页面健康检查**：自动检测页面状态，异常自动恢复
- **异常检测和处理**：识别反爬虫、错误页面、速率限制
- **智能重试机制**：指数退避算法，根据错误类型决定重试

#### 3. Windows 兼容性
- **改进浏览器查找**：支持注册表、多路径、环境变量
- **系统要求检查**：启动时自动检测并提供友好提示
- **打包配置优化**：包含所有必要文件

## 🚀 快速开始

### 开发环境

```bash
# 1. 安装依赖
cd electron
npm install

cd ../license-tool
npm install

# 2. 开发模式运行
cd electron
npm run dev

# 或运行授权工具
cd license-tool
npm start
```

### 打包发布

```bash
# 用户端应用
cd electron
npm run package
# 输出: electron/release/镜核 Setup 0.1.0.exe

# 授权工具
cd license-tool
npm run package
# 输出: license-tool/release/镜核授权签发工具 Setup 1.0.0.exe
```

### 支持的查询网站
1. **W-001** - 信用中国（严重失信、税收违法）
2. **W-002** - 中国执行信息公开网（失信被执行人）
3. **W-003** - 中国政府采购网（政府采购违法失信）
4. **W-004** - 军队采购网（暂停名单、失信名单）
5. **W-005** - 全国企业破产重整案件信息网

## 🔐 授权系统

### 授权流程
1. 用户运行应用，获取机器码
2. 管理员使用授权工具生成 `.jinghe-license` 文件
3. 用户导入授权文件
4. 应用验证授权并激活功能

### 授权特性
- **机器码绑定**：基于硬件 UUID 和 MachineGuid
- **RSA 签名**：使用 RSA-SHA256 签名验证
- **有效期控制**：支持永久授权和有效期授权
- **功能控制**：可配置授权功能特性

## ⚠️ 重要提示

### 安全注意事项
1. **授权工具**：仅供内部使用，包含私钥，不要泄露
2. **私钥保管**：`signer.js` 必须妥善保管和备份
3. **用户数据**：所有查询在本地执行，不经过第三方服务器

### 合规使用
1. 遵守网站使用条款
2. 控制访问频率，避免过度请求
3. 仅用于合法的企业资质核查
4. 保护查询结果的隐私和安全

## 🛠️ 故障排除

### 常见问题
- **找不到浏览器** → 安装 Chrome/Edge 或设置 `EDGE_EXE` 环境变量
- **验证码识别失败** → 自动重试，检查网络连接
- **页面加载超时** → 增加重试次数，检查防火墙
- **授权文件无效** → 检查机器码是否匹配，文件是否完整

详细解决方案见：[用户指南.md - 常见问题](./用户指南.md#常见问题)
